# Changelog

## 1.0.0 (2026-07-29)

First versioned release, bringing the skill under the CFOforIT Build Standards charter (v1.8). The public repo had no standards gate, so this skill had never been validated against it.

**One substantive change:** added a "Where this sits" section. The skill previously referenced no other skill at all, so anyone who reached it first never learned that `eos-setup` exists — and the vision plan imports into a dashboard that setup creates. It now names what it does not do (leadership team, scorecard, meeting schedule), says why the split is deliberate (one interview long enough for both produces a rushed vision, which is the part worth doing slowly), and points forward to `eos-meeting-prep`. Found by a new eval asserting the cross-reference exists.

Recorded classifications and why:

- **`autonomy_tier: draft-for-review`** — it drafts vision content with the user and writes a file they import. Nothing is applied on their behalf.
- **`blast_radius: private`** — the draft stays with the team that asked for it.
- **`model_tier: opus`** — drafting a core focus, BHAG, three-year picture and one-year plan is strategy writing, the same judgment class as this firm's other opus-tier narrative work. A weak vision draft is worse than a blank page, because a team will edit a bad draft instead of rethinking the question.
- **`trust_level: external`** — public marketplace skill, run outside the firm on the user's own data.
